# zunda-graph-kanban

YouTube「ずんだもんの実験道具箱」シリーズ **グラフエンジニアリング徹底入門** で作るコードです。
AI エージェントの処理を「状態を持つグラフ」として設計する回で、題材は **AI と人が合流する簡易かんばん**。

動画を見ながら手元で動かせるように、**回ごと・段階ごとのフォルダ**に分けてあります。

## 段階

| フォルダ | 何が入っているか | 対応する回 |
|---|---|---|
| `steps/01_imperative/` | `while` と `if` で素直に書いた版（26行） | 第1回 |
| `steps/02_graph_v1/` | 同じ処理をグラフに組み直した版 | 第1回 |
| `steps/03_checkpoint/` | 1歩ごとに保存する版（checkpointer） | 第2回 |
| `steps/04_human/` | 人の承認で止まる版（interrupt） | 第3回 |
| `steps/05_parallel/` | 枚数ぶんの枝を開く版（Send）＋わざと壊した版 | 第4回 |
| `shared/` | 全段階が共有する状態の型とノード | — |

`run_ep01.py` 〜 `run_ep04.py` が各回の実行入口です。

## 動かす

```
pip install "langgraph==1.2.11" langgraph-checkpoint-sqlite
python run_ep01.py
```

第3回のサーバ経由の確認だけ `langgraph-cli` が要ります。

## 環境（動画の収録時点）

langgraph 1.2.11 / Python 3.14.4 / Linux aarch64（2026-08-26 取得）。
動画に出る行数・件数はこの環境で1回ずつ実行した実測値です。

- **画面（UI）は作りません。** ターミナルで動かし、盤面は文字で表示して確かめます
